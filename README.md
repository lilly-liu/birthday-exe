# birthday.exe

A static birthday card using HTML, CSS and JavaScript.

Open `index.html` in a browser, or serve the folder locally with `python3 -m http.server 8000`.

## GitHub Pages

Create a repository for the card, commit these files and push to the `main` branch. In repository Settings → Pages, select Deploy from a branch, then choose `main` and `/ (root)`.

The childhood photos are included in the site, so keep in mind that a public Pages site makes them accessible to anyone with the URL.
